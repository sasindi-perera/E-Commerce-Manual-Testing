# 🧪 SauceDemo Manual Testing Project

## 📌 Overview

A manual QA testing project for the SauceDemo e-commerce web application. The project covers requirement analysis, test scenario and test case design, test data preparation, test execution, and defect reporting.

## 🧪 Modules Tested

- Login & Logout
- Products & Sorting
- Shopping Cart
- Checkout
- Navigation
- Form Validation

## 🛠️ Tools

- Microsoft Excel
- Microsoft Word
- Google Chrome
- Git & GitHub

## 🎯 Objective

To gain practical experience in manual software testing, test case design, test execution, defect reporting, and QA documentation.
